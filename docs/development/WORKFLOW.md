# Human and AI development workflow
> Last reviewed: 2026-09-13

1. Read context/map and relevant module docs.
2. Inspect actual source and migrations; documentation may be stale.
3. Identify impact with `DOCUMENTATION_MATRIX.md`.
4. Make a minimal layered change.
5. Build and execute relevant tests; report exact results.
6. Update docs, map, TODO and worklog in the same change.
7. Review `git diff` for code, migration, configuration and documentation consistency.
