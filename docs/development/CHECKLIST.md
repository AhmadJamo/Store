# Change checklist
> Last reviewed: 2026-09-13

## Every change
- [ ] Read source and relevant docs.
- [ ] Preserve authorization and tenant/accounting boundaries where applicable.
- [ ] Build; run relevant tests or honestly record absence.
- [ ] Update map/module and worklog.

## Feature/bug/UI
- [ ] DTO/service/controller/view impact reviewed.
- [ ] Backend authorization and CSRF reviewed.
- [ ] Validation and error handling reviewed.

## Entity/database/accounting
- [ ] Configuration and migration added/reviewed.
- [ ] Constraints, concurrency and delete behaviour reviewed.
- [ ] Accounting posting/reversal implications documented.

## Permission/security
- [ ] Definition, seed, backend action and navigation checked.
- [ ] No secrets/log leaks introduced.
