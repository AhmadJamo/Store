# تدقيق الأمان / Security Audit

## ضوابط قوية مثبتة

- هوية ASP.NET (إطار هوية مايكروسوفت)، تشفير كلمات المرور، قفل، حد طلبات، HTTPS وHSTS في الإنتاج.
- رمز منع تزوير عام لكل تغييرات MVC (نموذج-عرض-متحكم).
- صلاحيات خادم وأدوار مملوكة للشركة؛ Admin العام لا يمنح إدارة شركة.
- عزل شركة متعدد الطبقات وعلاقات SQL مركبة.
- رموز بوابة المورد ومفاتيح API (واجهة برمجية) عشوائية، مخزنة كبصمات، محددة النطاق ومنتهية/قابلة للإلغاء.
- حماية SSRF (تزوير طلب من الخادم) في callbacks عبر HTTPS ومنع الشبكات الخاصة وتثبيت عنوان DNS.
- 756 فحص أمان/انحدار ناجح في 2026-10-16.
