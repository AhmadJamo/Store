## `MOD-024D` — حجز مخزون طلب البيع / Sales order reservations

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة المبيعات

اكتمل `MOD-024C`: تحويل العرض المقبول وطلبات البيع والتأكيد والإلغاء والموافقات تعمل في Angular، وبقي MVC افتراضياً.

### الهدف

- نقل صفحة الحجز الحالية لطلب البيع المؤكد مع عرض المطلوب والمحجوز والمتبقي وسجل الحجوزات.
- نقل إنشاء الحجز وتحريره بالصلاحيات المستقلة الحالية وباختيار المستودع والموقع بالاسم.
- إبقاء أهلية المستودع/الموقع والكميات المتبقية وسياسة النقص والتتبع والتزامن وسلطة المخزون في الخادم.

### القبول

- كل عمليات Sales Order Reservation الحالية تعمل وتُختبر في Angular عبر Application layer.
- لا يغيّر Angular OnHand ولا يحسب الرصيد الموثوق؛ الحجز يغيّر Reserved فقط وفق الخدمة الحالية.
- كل mutation يحتفظ بصلاحيته وantiforgery وrowversion/idempotency حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
