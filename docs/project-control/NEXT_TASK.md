## `P2-CUS-040E / CUS-030B` — الإعدادات التجارية الافتراضية للزبون

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتمل `CUS-030A`: يمكن للشركة اختيار حساب رقابة مشترك، حساب مستقل تلقائي أو اختيار يدوي. السياسة مستقبلية وتحمي التاريخ، وأي انتقال لاحق مرتبط بمبيعات يحتاج مسار انتقال مضبوط.

### الهدف التالي

إضافة إعدادات الزبون التجارية التي ستستهلكها مستندات البيع المستقبلية: شروط الدفع، العملة، قائمة السعر، مندوب/فريق البيع والوضع الضريبي، مع إعادة استخدام تأسيس `SAL-020` (التسعير والضريبة) وعدم إنشاء محركات مكررة.

### الضوابط

- الإعدادات افتراضية وقابلة للتجاوز فقط بصلاحية وقاعدة عمل واضحة.
- المستند الجديد يثبت لقطة القيم؛ تغيير ملف الزبون لا يعيد كتابة مستند قديم.
- لا تنشأ ذمم أو قيود أو أثر مخزون في هذه المرحلة.
- الخيارات غير الموجودة فعليًا مثل قائمة السعر/الفريق تُبنى في شريحتها المالكة أو تؤجل، ولا تعرض كميزة وهمية.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
