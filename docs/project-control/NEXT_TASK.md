- كل عمليات Purchase Document Reversal الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
- لا يستطيع Angular عكس مستند له اعتماديات لاحقة أو مخزون مستهلك/معاد تقييمه أو تكرار أثر العكس.
