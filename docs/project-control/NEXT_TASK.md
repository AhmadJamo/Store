## `P2-SAL-050C / SAL-030` — عروض أسعار المبيعات

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتمل `SAL-020B`: أصبحت قوائم الأسعار وقواعدها وافتراضي الزبون ومحرك التقييم القابل للتفسير منفذة، مع بقاء البيع الفوري و`POS` (نقطة البيع) دون تغيير.

### الهدف التالي

إضافة عرض سعر مبيعات مستقل يبدأ كمسودة، يثبت بيانات الزبون والعنوان والمنتج والوحدة والسعر والعملة وسعر الصرف والضريبة، ويدعم الإرسال والقبول والرفض والانتهاء والإلغاء مع تاريخ دلالي. لا يغيّر عرض السعر المخزون ولا ينشئ قيدًا محاسبيًا.

### الضوابط

- يستخدم العرض خدمة التسعير المنفذة ثم ينسخ النتيجة إلى لقطات تاريخية لا تتغير بتعديل القوائم لاحقًا.
- البحث عن المنتج يدعم الاسم والكود والباركود، وتبقى المعرفات داخلية.
- الانتقالات مسموحة حسب الحالة فقط، وكل عملية تغيير تحتاج صلاحية ورمز منع تزوير وتزامن صف.
- قبول العرض لا ينقص المخزون؛ إنشاء طلب البيع الناتج يكون خطوة منفصلة ومحمية، ويظهر رابط المستند بدل زر قبول متكرر.
- الشاشة عربية/إنجليزية ومتجاوبة دون تمرير أفقي، والأرقام تستخدم الدقة المطلوبة دون أصفار زائدة.
- الأخطاء القابلة للحل تعرض رابط الإعداد المناسب، وكل نجاح يعرض الخطوة التالية وشرحها القصير حسب صلاحية المستخدم.

### قبول المرحلة

عرض كامل من الواجهة إلى قاعدة البيانات مع عزل شركتين، لقطات ثابتة، انتقالات حالة واختبارات تزامن ومنع تكرار، وصفر حركة مخزون أو أثر محاسبي.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
