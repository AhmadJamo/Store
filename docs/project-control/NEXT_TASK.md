## `P2-SAL-050H / SAL-080` — ترحيل ذمم الزبائن والمحاسبة

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتمل `SAL-070`: يمكن إنشاء فاتورة زبون جزئية أو متعددة حسب سياسة الكمية المسلّمة أو المطلوبة، واعتمادها أو إلغاؤها مع تحرير الكمية، دون أثر مخزون أو قيد محاسبي أو تحصيل.

### الهدف التالي

إضافة ترحيل محاسبي مضبوط للفاتورة المعتمدة: مدين ذمم الزبائن، ودائن الإيراد وضريبة المخرجات، مع حالة Posted (مرحّلة) وعكس Reversed (معكوسة) مانعين للتكرار. لا يُعد الترحيل تحصيلًا؛ يبقى الدفع والتخصيص لـ `SAL-090`.

### الضوابط

- لا تُرحّل إلا فاتورة Approved (معتمدة)، ولا يمكن تكرار الترحيل أو العكس.
- حل حساب الذمم حسب سياسة الشركة الحالية مع حفظ الحساب المستخدم داخل دليل الترحيل.
- تثبيت حساب الإيراد وضريبة المخرجات من لقطات الفاتورة دون إعادة تسعير أو إعادة احتساب المصدر.
- احترام الفترة المالية والفرع والعملة وسعر الصرف والتوازن المحاسبي.
- إنشاء قيد واحد فريد حسب مصدر الفاتورة، وربط الفاتورة والقيد والذمة بعلاقة قابلة للتدقيق.
- العكس لا يحذف التاريخ؛ ينشئ أثرًا معاكسًا مضبوطًا ويمنع التسوية غير الصحيحة.
- زر الترحيل يختفي بعد النجاح ويظهر Posted (مرحّلة) مع رابط القيد؛ الأخطاء القابلة للعلاج تعرض زر الإعداد المناسب.
- لا إنشاء Payment (دفعة) أو اعتبار الفاتورة مسددة؛ التحصيل والتخصيص يخصان `SAL-090`.

### قبول المرحلة

فاتورة معتمدة تُرحّل مرة واحدة إلى ذمم/إيراد/ضريبة متوازنة، ويمكن عكسها مرة واحدة بدليل كامل، دون تغيير التسليم أو المخزون أو COGS (تكلفة البضاعة المباعة) ودون اعتبارها تحصيلًا.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
