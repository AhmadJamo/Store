## `P2-SAL-050J / SAL-100` — المرتجعات والإشعارات الدائنة

> الحالة: APPROVED — IN PROGRESS (2026-10-21)

اكتمل `SAL-090`: يمكن تسجيل دفعة زبون مستقلة وتوزيعها جزئيًا أو كليًا على فاتورة مرحلة واحدة أو عدة فواتير للزبون والعملة نفسيهما. حالة السداد والرصيد مشتقان من التوزيعات المرحلة، والقيد وفروق الصرف والعكس محفوظة دون أي تغيير في المخزون.

### المنجز: SAL-100A

أصبح طلب المرتجع مرتبطًا بسطر تسليم مُرحّل، مع مسودة وإرسال واعتماد ورفض وإلغاء، وحماية مجموع الكميات المفتوحة، دون أثر مخزون أو محاسبة أو إشعار دائن. طُبّق الترحيل 127 ونجح 947 فحصًا.

### الهدف التالي: SAL-100B

استلام الطلب المعتمد وفحص الكميات والهويات المتتبعة، ثم اختيار إعادة تخزين أو حجر أو رفض/إتلاف بصورة صريحة، مع إبقاء الإشعار الدائن والاسترداد منفصلين.

### الضوابط

- إبقاء `SalesReturn` القديم لمسار البيع الفوري وعدم تحويل بياناته أو إعادة كتابتها.
- طلب إرجاع مستقل بحالات واضحة وموافقة قبل الاستلام.
- عدم قبول كمية تتجاوز الكمية المسلّمة والقابلة للإرجاع بعد طرح المرتجعات السابقة.
- ربط المنتج والدفعة/الرقم التسلسلي بالتسليم الأصلي عند وجود تتبع.
- فحص المستلم وتحديد إعادة تخزين أو حجر أو إتلاف بصورة صريحة.
- إنشاء إشعار دائن مستقل مرتبط بفواتير مرحلة؛ لا يُعد استردادًا نقديًا تلقائيًا.
- قيود مخزون وذمم وضريبة وتكلفة متوازنة، قابلة للمطابقة والعكس، دون حذف التاريخ.
- إخفاء الإجراء المكتمل وإظهار الحالة والخطوة التالية وروابط المستندات الناتجة.

### قبول المرحلة

يمكن تتبع طلب الإرجاع من التسليم حتى قرار البضاعة والإشعار الدائن، وتبقى الكمية والقيمة والذمة والمخزون والقيود قابلة للمطابقة، دون المساس بمسار البيع الفوري القديم.

وافق المستخدم صراحة بعبارة «كمل». اكتمل `SAL-100A` في 2026-10-21، وتستمر المرحلة إلى `SAL-100B` ضمن الموافقة نفسها.
