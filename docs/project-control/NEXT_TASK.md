## `MOD-028F` — مرفقات وطباعة التوريد / Purchase Sourcing Attachments and Print

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة الشاشات المتبقية

اكتمل `MOD-028E` لتدقيق الشركة وبقي `Language` السطح الوحيد غير المربوط. كشف فحص التكافؤ أن Angular
للتوريد موجود، لكنه يسقط المرفقات عند إنشاء RFQ ولا يوفر تنزيل المرفق أو العرض القابل للطباعة الموجودين في MVC.

### الهدف

- الحفاظ على مرفقات إنشاء RFQ عبر عقد multipart محدود ومتحقق منه بدل تصفيرها في API.
- إضافة تنزيل مرفق tenant-safe ومصرح به، وعرض RFQ قابل للطباعة دون كشف مسارات التخزين.
- إضافة رفع/عرض/تنزيل/طباعة ثنائية اللغة وRTL إلى Angular Sourcing مع حالات الخطأ والوصولية.

### القبول

- الرفع يحافظ على حدود النوع/الحجم/العدد الحالية في Application، وكل قراءة أو تنزيل يتحقق من الشركة والصلاحية.
- لا يصل اسم ملف أو مسار مقدم من العميل إلى التخزين دون التطبيع الحالي، والتنزيل يعيد اسمًا ونوعًا آمنين.
- العرض القابل للطباعة يحافظ على بيانات RFQ الحالية ولا ينشئ أو يغيّر مستند أعمال.
- اختبارات API وAngular والأمان، سجل الترحيل، وبوابة القبول كاملة؛ MVC يبقى افتراضيًا.
