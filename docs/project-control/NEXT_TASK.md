## `MOD-023G` — دفعات المورد / Supplier payments

### الهدف

- عرض تخصيصات الفواتير وأدلة العملة والقيد والتسوية الموجودة دون اختراع سلوك جديد.

- كل عمليات Supplier Payment الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
