## `MOD-029B` — مصالحة البيانات المصرح بها / Authenticated Same-Data Reconciliation

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة القبول الشامل

اكتمل `MOD-029A` بالمصفوفة المولدة، قبول العرض والمتصفح، عينات الحدود read-only، الأداء وتمرين الرجوع.
لا يوجد ملف Playwright storage-state حاليًا، لذلك لم يُدّعَ إثبات بيانات مصرح بها.

### الهدف

- إضافة runner يستهلك storage-state خارجيًا دون قراءة أو تسجيل بيانات الدخول.
- مقارنة عينات قراءة من الهوية/الثقافة، فاتورة زبون أو قيد مالي، ورصيد/رؤى مخزون على نفس جلسة Demo.
- مقارنة الهوية والحالة والرقم والمبلغ/الكمية والأسماء فقط؛ لا mutation ولا تصدير حساس.
- حفظ تقرير منقح يذكر المسارات والحقول والنتيجة دون cookies أو tokens أو PII غير لازمة.

### القبول

- session وCSRF واللغة تعمل في MVC وAngular/API بنفس tenant والمستخدم.
- ثلاث عينات عالية المخاطر على الأقل تتطابق في الحقول المعتمدة أو توثق فرقًا حقيقيًا قابلًا للإصلاح.
- لا تُحفظ الجلسة داخل Git ولا تظهر cookie/token في المخرجات.
- عند غياب storage-state يفشل التشغيل برسالة إجرائية واضحة وأمر capture؛ لا يتحول إلى نجاح أو skip صامت.
