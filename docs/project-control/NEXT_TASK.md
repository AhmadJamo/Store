## `MOD-024F` — فواتير العملاء / Customer invoices

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة المبيعات

اكتمل `MOD-024E`: إنشاء وترحيل وإلغاء تسليمات المبيعات يعمل في Angular، وبقي MVC افتراضياً.

### الهدف

- نقل قائمة وتفاصيل وإنشاء فواتير العملاء من الكمية المؤهلة في طلب البيع.
- نقل الاعتماد والإلغاء مع عرض اللقطات ومصدر التسليم والتقدم التراكمي.
- إبقاء أهلية ordered/delivered والكميات التراكمية والترقيم واللقطات والتزامن داخل الخادم.

### القبول

- كل عمليات Customer Invoice الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
- لا يعيد Angular تسعيرًا أو يحسب كمية/رصيدًا موثوقًا، ولا ينشئ قيد ذمم قبل خطوة الترحيل المنفصلة.
- كل mutation يحتفظ بصلاحيته وantiforgery وrowversion/idempotency حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
