## `P2-SAL-050A / SAL-020` — أساس التسعير والضريبة ووحدة البيع

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتملت قاعدة الزبون `CUS-005..030B`: الهوية والملف وجهات الاتصال والعناوين وسياسة حساب الذمم، ثم مهلة الدفع والعملة والضريبة/الإعفاء كافتراضات مستقبلية. لم تُنشأ قائمة سعر أو فريق مبيعات وهميان.

### الهدف التالي

بناء مصدر واحد حتمي للتسعير والضريبة ووحدة البيع يدعم المنتج/الزبون/المجموعة/الكمية/الوحدة/العملة/التاريخ، ويعيد نتيجة تشرح السعر الأصلي والنهائي والقاعدة والمصدر. بعد وجوده يمكن ربط قائمة سعر حقيقية بالزبون دون تكرار منطق السعر.

### الضوابط

- لا يتغير مسار البيع الفوري القديم دون بوابة انتقال واختبارات توافق.
- الأولوية والتقريب وتحويل الوحدة وسعر الصرف والضريبة تكون قابلة للتهيئة بقواعد واضحة، لا حقولًا حرة متعارضة.
- كل مستند جديد يثبت لقطة السعر والعملة والضريبة؛ تعديل القاعدة لاحقًا لا يغيّر التاريخ.
- لا أثر مخزون أو قيد محاسبي من تعريف قاعدة سعر وحدها.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
