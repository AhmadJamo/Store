## `UX-013` — أعمار الذمم ومصالحة الأستاذ المساعد / AR/AP Aging and Subledger Reconciliation

> الحالة: APPROVED BY OWNER

بعد اكتمال التقارير المالية والقيود اليدوية، ما زال المحاسب يفتقد رؤية موحدة للذمم المدينة والدائنة حسب العمر
ومصالحتها مع حسابات السيطرة في الأستاذ العام.

### النطاق المحدود

- إنشاء قراءة خادمية للذمم المدينة والدائنة كما في تاريخ محدد، باستخدام القيم الدفترية بعملة الشركة.
- تصنيف الأرصدة إلى حالي، 1–30، 31–60، 61–90، وأكثر من 90 يومًا حسب تاريخ الاستحقاق.
- عرض إجمالي كل زبون/مورد ومستند مع روابط آمنة للفواتير والدفعات والإشعارات والقيود.
- مقارنة إجمالي كل أستاذ مساعد بحساب/حسابات السيطرة المهيأة وإظهار الفرق صراحة.
- حفظ تاريخ التقرير والتبويب والفلاتر الآمنة، وعدم حساب الأعمار أو الأرصدة في Angular.
- إضافة اختبارات ذهبية للعزل، الدفعات الجزئية، الإشعارات، العكس، تعدد العملات، الحدود الزمنية وRTL/LTR.

### القبول

- مجموع أعمار الذمم يطابق الرصيد القائم للمستندات كما في التاريخ المحدد دون ازدواج دفعات أو إشعارات.
- تظهر المصالحة قيمة الأستاذ المساعد والأستاذ العام والفرق، مع مصدر واضح لكل رقم.
- لا تدخل مسودة أو مستند ملغي أو شركة أخرى، وتستخدم القيم الدفترية المجمدة بعملة الشركة.
- نجاح اختبارات الطبقات والبيانات الذهبية وAngular والوصول وRTL/LTR والموبايل والميزانيات.

### خارج النطاق

- إنشاء تحصيل أو دفع، إرسال كشوفات، رسائل تذكير، حدود ائتمان أو وعود سداد.
- تعديل المستندات أو القيود، إعادة تقييم العملات، التدفقات النقدية أو التوحيد متعدد الشركات.
- بناء مخزن تقارير منفصل أو تغيير حسابات السيطرة الحالية دون قرار مستقل.
