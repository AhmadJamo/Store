### الهدف التالي

توسيع أمر التحقق الموحد من فحوص البناء الحالية إلى بوابة قبول قابلة لإعادة الاستخدام لكل موجة Angular:

- فحوص accessibility ثابتة ومسارات متصفح مركزة لـRTL/LTR ولوحة المفاتيح والحالات الأساسية؛
- smoke/E2E حقيقي لعقود session وواجهات القراءة المسموحة دون تخزين أسرار في المستودع؛
- تقرير نتيجة واحد يوضح ما نُفذ وما تخطاه بسبب غياب بيئة أو بيانات اعتماد؛
- إبقاء Web/backend regression وAngular tests/build وسياسة external SCSS ضمن البوابة نفسها.
