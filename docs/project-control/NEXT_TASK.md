## `UX-011` — أساس التقارير المالية / Read-only Financial Reporting Foundation

> الحالة: APPROVED BY OWNER

بعد اكتمال شجرة الحسابات ودليل القيود، بقيت أهم فجوة قراءة محاسبية: لا توجد ميزان مراجعة أو قوائم مالية
مشتقة من القيود المرحلة. هذه المرحلة تبني قراءة مالية خادمية قابلة للمصالحة دون إضافة قيود يدوية.

### النطاق المحدود

- إنشاء قراءة خادمية لميزان المراجعة حسب فترة وتاريخ نهاية مع إجمالي مدين/دائن وفارق صريح.
- بناء الميزانية وقائمة الدخل من أنواع الحسابات والقيود المرحلة فقط، مع روابط حفر آمنة لدليل القيود.
- توثيق تعريف كل رقم، استبعاد المسودات، ومعالجة القيود المعكوسة بوضوح.
- حماية التقارير بصلاحية قراءة محاسبية موجودة وعدم حساب الأرصدة في Angular.
- إضافة بيانات اختبار ذهبية للعزل والتوازن والفترة والحسابات الهرمية وRTL/LTR.

### القبول

- ميزان المراجعة يتطابق مع مجموع القيود المرحلة ضمن الفترة ويظل متوازنًا.
- الميزانية وقائمة الدخل تعرضان تعريفات واضحة وقيمًا خادمية قابلة للحفر والمصالحة.
- لا تدخل مسودة أو شركة أخرى في النتائج، وتبقى العملات ضمن حدود عملة الشركة الحالية.
- نجاح اختبارات الطبقات والبيانات الذهبية وAngular والوصول وRTL/LTR والموبايل والميزانيات.

### خارج النطاق

- التدفقات النقدية، التوحيد متعدد الشركات، الموازنات والتحليلات المتقدمة.
- إنشاء قيود يدوية أو تعديل/حذف القيود أو تغيير قواعد الترحيل الحالية.
- حذف MVC أو مسارات الرجوع أو توسيع الصلاحيات دون قرار منفصل.
