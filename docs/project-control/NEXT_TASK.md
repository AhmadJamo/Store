## `MOD-028E` — تدقيق الشركة / Tenant Audit Events

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة الشاشات المتبقية

اكتمل `MOD-028D` للرؤى والمصالحة وبقي سطحا Audit Events وLanguage. تدقيق الشركة الحالي يقرأ أحداث الشركة
ويصدّر CSV محدودًا لغرض صريح، مع صلاحية مستقلة للحقول الحساسة.

### الهدف

- إضافة API لصفحة الأحداث وتصدير CSV فوق `AuditEventReadService` الحالية.
- اشتقاق عرض الحقول الحساسة على الخادم، وعدم قبول قرار حساس من العميل.
- نقل كل المرشحات والترقيم وأغراض التصدير المسموحة وتنزيل الملف إلى Angular.

### القبول

- القراءة تتطلب `AuditEvents.View`، والتصدير يتطلب معها `AuditEvents.Export` وantiforgery.
- `AuditEvents.ViewSensitive` يحدد الحقول الحساسة خادميًا؛ التصدير محدود بـ5,000 صف وغرض allowlisted ويسجل حدثًا دلاليًا.
- Angular ثنائي اللغة وRTL ويغطي المرشحات والترقيم والحالات والتحميل الآمن للملف.
- اختبارات التنقيح والصلاحيات والتصدير وبوابة القبول كاملة؛ MVC يبقى افتراضيًا.
