## `MOD-029C` — قبول الوحدات عالية المخاطر / High-Risk Module Acceptance

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة القبول الشامل

اكتمل `MOD-029B` بجلسة مشغل خارجية مستثناة من Git: نجحت الهوية/الثقافة، الحالة المالية الفارغة،
وعينة مخزون فعلية عبر MVC وAPI دون mutation أو كشف cookie/token.

### الهدف

- توسيع القبول المصرح به إلى مجموعات المبيعات والمشتريات والمخزون والمحاسبة والإدارة حسب صلاحيات المشغل.
- تشغيل قراءات ممثلة لكل مجموعة مع تحقق من status/content type/tenant boundary، دون أوامر كتابة.
- إنتاج تقرير outcome-only يبين المجموعة والمسار والنتيجة ولا يسجل قيم الأعمال أو أسرار الجلسة.
- إبقاء MVC افتراضيًا؛ لا يبدأ تمرين cutover التدريجي قبل نجاح هذه المجموعة.

### القبول

- تغطي الأدلة المصرح بها كل مجموعة عالية المخاطر يملك المشغل صلاحية قراءتها، مع ثلاث مجموعات أعمال على الأقل.
- كل probe للقراءة فقط، ولا ينفذ POST/PUT/PATCH/DELETE أو تنزيلًا حساسًا.
- الفشل أو غياب الصلاحية/العينة يظهر صراحة ولا يتحول إلى نجاح صامت.
- البوابة الثابتة وMOD-029B تبقيان ناجحتين، ولا تتغير presentation defaults.
