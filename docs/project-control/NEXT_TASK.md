## `UX-012` — أساس القيود اليدوية المضبوطة / Controlled Manual Journal Foundation

> الحالة: APPROVED BY OWNER

بعد اكتمال شجرة الحسابات ودليل القيود والتقارير المالية، بقيت فجوة تشغيل محاسبية أساسية: لا يستطيع المحاسب
إنشاء مسودة قيد يدوي متوازن ثم ترحيله أو عكسه ضمن نفس ضوابط الفترات الحالية.

### النطاق المحدود

- إضافة صلاحيات مستقلة ودقيقة لعرض/إنشاء/ترحيل/عكس القيود اليدوية، دون توسيع `JournalEntries.View`.
- إنشاء مسودة متعددة الأسطر بأسماء الحسابات والفروع والمستودعات، مع تحقق مدين/دائن خادمي ورسائل ثنائية اللغة.
- تمرير الترحيل والعكس فقط عبر بوابة القيود والفترات الحالية مع idempotency ومصدر محايد للغة.
- حفظ مسودة النموذج في الذاكرة فقط وبحقول allowlist مناسبة، مع تحذير مغادرة واضح.
- إبقاء القيود المرحلة ثابتة، ومنع التعديل والحذف، وربط النجاح بالتفاصيل والتقارير المالية.
- إضافة اختبارات ذهبية للصلاحيات والعزل والتوازن والفترة ومنع التكرار والعكس وRTL/LTR.

### القبول

- لا يمكن ترحيل قيد غير متوازن أو داخل فترة غير مفتوحة أو من دون الصلاحية الدقيقة.
- إعادة إرسال الأمر لا تنشئ قيدًا ثانيًا، والعكس ينشئ قيدًا معاكسًا منفصلًا ويحفظ الأصل.
- لا تظهر حسابات/فروع/مستودعات شركة أخرى ولا تُقبل معرّفاتها.
- نجاح اختبارات الطبقات والبيانات الذهبية وAngular والوصول وRTL/LTR والموبايل والميزانيات.

### خارج النطاق

- تعديل أو حذف قيد مُرحّل، الترحيل المجمع، الاستيراد، القوالب الدورية والاعتماد متعدد المراحل.
- التدفقات النقدية، الإقفال السنوي، التوحيد متعدد الشركات والموازنات.
- تغيير قواعد القيود التشغيلية للمبيعات والمشتريات والمخزون أو حذف MVC.
