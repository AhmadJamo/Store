# المهمة التالية الوحيدة / Next Task

## UX-015 — تنفيذ إقفال الفترة المضبوط / Controlled Period-Close Execution

> الحالة: PROPOSED — AWAITING OWNER APPROVAL

اكتملت UX-014 كتقرير تدفق نقدي وقائمة تحقق للقراءة فقط. الخطوة التالية المقترحة تنقل النظام من عرض الموانع إلى
تنفيذ إقفال مضبوط؛ لذلك لا تبدأ دون موافقة مالك صريحة على قواعد الانتقال والأثر المحاسبي.

### النطاق المقترح

- انتقال مضبوط من Open إلى SoftClosed ثم Closed مع سبب، مستخدم، وقت وrowversion.
- إعادة تشغيل فحوص UX-014 على الخادم داخل نفس أمر الإقفال ومنع الإقفال عند وجود مانع مع دليل واضح.
- فصل صلاحيات العرض، الإقفال الناعم، الإقفال النهائي وإعادة الفتح، مع antiforgery وسجل تدقيق.
- قرار صريح حول قيود إقفال الإيراد/المصروف قبل تنفيذها؛ لا ينشئ النظام قيدًا تلقائيًا دون اعتماد القاعدة.
- واجهة ثنائية اللغة تعرض الحالة والأدلة وتمنع تكرار الإجراء.

### خارج النطاق

- التوحيد متعدد الشركات، الموازنات، التنبؤ، إعادة تقييم العملات أو تعديل مستندات المصدر.
- حذف أو تعديل قيود مرحّلة، أو تجاوز فروقات المصالحة آليًا.

لا يبدأ التنفيذ قبل موافقة المالك على هذا النطاق وعلى سياسة قيد الإقفال وإعادة الفتح.
