## `MOD-024H` — طلبات مرتجعات العملاء / Customer return requests

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة المبيعات

اكتمل `MOD-024G`: جميع عمليات دفعات العملاء الحالية، بما فيها التوزيع والترحيل والعكس، تعمل في Angular، وبقي MVC افتراضياً.

### الهدف

- نقل قائمة وتفاصيل وإنشاء طلبات مرتجعات العملاء من تسليم مرحّل.
- نقل الإرسال والاعتماد والرفض والإلغاء مع عرض الكميات المؤهلة والتاريخ.
- إبقاء ملكية التسليم والكميات التراكمية والأهلية والترخيص والتزامن داخل الخادم.

### القبول

- كل عمليات Customer Return Request الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
- لا يحسب Angular كمية مرتجع موثوقة، ولا يغيّر الطلب المخزون أو المحاسبة أو رصيد العميل.
- كل mutation يحتفظ بصلاحيته وantiforgery وrowversion/idempotency حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
