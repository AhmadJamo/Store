## `MOD-024C` — طلبات البيع / Sales orders

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة المبيعات

اكتمل `MOD-024B`: قائمة وإنشاء وتفاصيل وحالات وPDF عروض أسعار المبيعات تعمل في Angular، وبقي MVC افتراضياً.

### الهدف

- نقل قائمة وتفاصيل طلبات البيع الحالية وتحويل عرض السعر المقبول مرة واحدة.
- نقل تأكيد وإلغاء طلب البيع مع إظهار رابط المستند المصدر والحالة المكتملة بدل الأزرار المستهلكة.
- إبقاء اللقطات والترقيم والتزامن والموافقات وأهلية الانتقالات داخل Application layer والخادم.

### القبول

- كل عمليات SalesOrders الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
- لا يعيد Angular تسعير اللقطة ولا ينشئ حجزًا أو حركة مخزون أو قيدًا أثناء التحويل أو التأكيد.
- كل mutation يحتفظ بصلاحيته المستقلة وantiforgery وrowversion حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
