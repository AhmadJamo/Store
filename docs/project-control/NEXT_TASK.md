## `P2-SAL-050F / SAL-060` — تسليم طلبات البيع

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتمل `SAL-050`: يمكن حجز طلب البيع المؤكد كليًا أو جزئيًا من مستودع وموقع محددين، وتحرير الحجز وإعادة تخصيصه، مع بقاء الرصيد الفعلي والمحاسبة دون تغيير.

### الهدف التالي

إضافة مستندات تسليم مستقلة لطلب البيع المؤكد، تسمح بتجهيز وتسليم جزئي أو كامل، وتستهلك الحجز المحدد وتخفض المخزون الفعلي وتكتب حركة الكلفة والتتبع داخل معاملة واحدة.

### الضوابط

- لا يُنشأ التسليم إلا من طلب مؤكد وغير ملغي، ولا تتجاوز الكمية المسلّمة الكمية المطلوبة بعد طرح التسليمات السابقة.
- يسمح بأكثر من تسليم للطلب، ويحفظ كل تسليم خطوطه وحالته وتاريخه ونسخة التزامن الخاصة به.
- يستهلك الترحيل حجز السطر والموقع نفسه؛ أي كمية غير محجوزة أو غير متاحة تُرفض دون مخزون سالب ضمني.
- ينقص `OnHand` (الرصيد الفعلي) و`Reserved` (المحجوز) معًا، ويحافظ على `Available` (المتاح) بصورة صحيحة داخل معاملة واحدة.
- المنتجات المتتبعة تحفظ اللوط/الرقم التسلسلي وسياسة السحب، والمنتجات غير المتتبعة تستخدم خدمة الإزالة المركزية الحالية.
- أثر تكلفة البضاعة المباعة يحدث عند التسليم حسب قرار `SAL-005`، مع منع الترحيل المكرر ومراعاة الفترة المحاسبية.
- بعد اكتمال التسليم يختفي زر التسليم وتظهر الحالة وروابط مستندات التسليم؛ يبقى المتبقي فقط قابلًا للعمل.
- لا تنشئ هذه المرحلة فاتورة ذمم أو تحصيلًا؛ `SAL-070` يملك الفوترة.

### قبول المرحلة

تسليم جزئي/كامل قابل للتدقيق يستهلك الحجز وينقص المخزون ويثبت الكلفة مرة واحدة، مع عزل شركة وتزامن وتتبع ومنع تجاوز كمية الطلب، دون إنشاء فاتورة أو تحصيل.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
