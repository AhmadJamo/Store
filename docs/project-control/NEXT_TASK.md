## `P2-SAL-050G / SAL-070` — فواتير الزبائن

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL

اكتمل `SAL-060`: يمكن إنشاء تسليم جزئي أو كامل من حجز طلب البيع وترحيله مرة واحدة، فينقص المخزون الفعلي والمحجوز ويحفظ التتبع والكلفة ويرحّل تكلفة البضاعة المباعة، دون إنشاء فاتورة أو تحصيل.

### الهدف التالي

إضافة فاتورة زبون مستقلة تسمح بالفوترة الجزئية والمتعددة من كمية مصدر مؤهلة، مع سياسة واضحة للفوترة حسب المطلوب أو المسلّم، ودورة Draft/Approved/Posted/Reversed دون اعتبار الفاتورة دفعة.

### الضوابط

- لا تتجاوز الكمية المفوترة التراكمية كمية المصدر المؤهلة لكل سطر.
- المنتجات المخزنية تفوتر على المسلّم افتراضيًا؛ أي فوترة على المطلوب تحتاج سياسة شركة صريحة. الخدمات تبقى خاضعة لسياسة مصدر موثقة.
- تحفظ الفاتورة لقطات الزبون والعنوان والمنتج والوحدة والسعر والعملة وسعر الصرف والضريبة والمصدر دون إعادة كتابة العرض أو الطلب أو التسليم.
- إنشاء Draft واعتماده لا يعني الدفع، ولا ينقص المخزون ولا يعيد ترحيل COGS.
- `SAL-070` يملك المستند وحالته وأهلية الكميات؛ `SAL-080` يملك قيد الذمم/الإيراد/الضريبة إذا بقي الفصل المرحلي معتمدًا.
- الترحيل أو العكس، إن دخلا هذه الشريحة بعد قرار النطاق، يكونان مانعين للتكرار ويحترمان الفترة المالية والحسابات المهيأة.
- الأزرار أحادية التنفيذ تختفي بعد الإكمال وتظهر الحالة ورابط المستند؛ أي خطأ قابل للعلاج يعرض رابط الإعداد أو المصدر المناسب.

### قبول المرحلة

فاتورة زبون جزئية/متعددة قابلة للتدقيق لا تتجاوز مصدرها وتحافظ على اللقطات والتزامن وعزل الشركة، ولا تُعامل كتحصيل ولا تكرر أثر المخزون أو COGS.

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة.
