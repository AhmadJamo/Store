## `MOD-028G` — مزامنة لغة Angular والخادم / Server Culture Synchronization

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة الشاشات المتبقية

اكتمل `MOD-028F` لمرفقات وطباعة التوريد. بقي `Language` السطح الوحيد غير المربوط: Angular يغيّر اللغة
حاليًا داخل المتصفح فقط، بينما رسائل Problem Details المترجمة في طلبات API تتبع ثقافة الخادم المستقلة.

### الهدف

- إضافة endpoint داخلي محمي بـantiforgery يقبل فقط `ar-JO` أو `en-US` ويكتب cookie الثقافة HttpOnly الحالية.
- جعل تبديل Angular يزامن الخادم أولًا ثم يحدّث اللغة والاتجاه والتفضيل المحلي دون حالة نصف مكتملة.
- تسوية البداية بين ثقافة جلسة الخادم والتفضيل المحلي بسياسة حتمية، ثم ربط `Language` وإعادة توليد السجل النهائي.

### القبول

- القيم غير المدعومة تُرفض ولا تغيّر cookie؛ الطلب الآمن يحتاج مصادقة وantiforgery.
- بعد نجاح التبديل، طلب API التالي يعيد الرسائل وفق اللغة الظاهرة، مع بقاء العربية RTL والإنجليزية LTR.
- لا تُخزن أسرار أو رموز جلسة في المتصفح، ولا تصبح localStorage سلطة أمان أو مصدر ثقافة الخادم.
- اختبارات endpoint والتزامن والبداية، سجل ترحيل بصفر أسطح، وبوابة القبول كاملة؛ MVC يبقى افتراضيًا.
