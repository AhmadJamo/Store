## `UX-010` — تأسيس مساحة المحاسبة / Accounting Workspace Foundation

> الحالة: APPROVED BY OWNER

بعد اكتمال التنقل، بقيت فجوة المحاسبة الفعلية: شاشة الحسابات قائمة مسطحة ولا توجد قائمة قيود يومية قابلة للبحث.
هذه المرحلة تبني أساس القراءة والإدارة الآمنة قبل أي تقارير مالية أو قيود يدوية.

### النطاق المحدود

- مراجعة كيان الحساب وDTO والخدمة والمستودع والربط قبل أي تعديل.
- عرض شجرة حسابات حقيقية قابلة للتوسيع مع البحث والحالة، دون حساب الأرصدة في المتصفح.
- إضافة دليل قيود يومية مقروء بمرشحات وتصفح وخط انتقال إلى التفاصيل الحالية.
- إبقاء الترحيل تدريجيًا، والصلاحيات والـApplication layer والـUnitOfWork هي السلطة.
- إضافة اختبارات للهيكل، عزل الشركة، الصلاحيات، التصفح وRTL/LTR.

### القبول

- الحسابات تظهر بهيكل أب/أبناء صحيح من بيانات الخادم مع منع الحلقات عند الإدارة.
- قائمة القيود تعرض أدلة متوازنة ومصفحة ولا تكشف شركة أخرى.
- المركز والبحث والتبويبات يفتحون الصفحات الجديدة ويحفظون المرشحات الآمنة.
- نجاح اختبارات الطبقات وAngular والبناء والوصول وRTL/LTR والموبايل والميزانيات.

### خارج النطاق

- القوائم المالية والميزانية وقائمة الدخل والتدفقات النقدية.
- إنشاء قيود يدوية أو تغيير قواعد الترحيل الحالية.
- حذف MVC أو مسارات الرجوع أو توسيع الصلاحيات دون قرار منفصل.
