## `MOD-028D` — رؤى المخزون والمصالحة / Inventory Insights and Reconciliation

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة الشاشات المتبقية

اكتمل `MOD-028C` للمسح التشغيلي وبقيت أربعة أسطح. السطحان التاليان للقراءة فقط: الأول يصنف النشاط والبطيء
والراكد والانتباه حسب المستودع، والثاني يصالح أرصدة المخزون مع السجل بترقيم صفحات ومرشح استثناءات.

### الهدف

- إضافة عقدي API للقراءة فقط فوق `InventoryInsightsService` و`InventoryReconciliationService`.
- نقل مرشحات المستودع والبحث وحالة النشاط وحدود البطيء/الراكد والانتباه، ثم الاستثناءات والترقيم في المصالحة.
- إظهار المنتجات والمستودعات والمواقع والأرقام المحسوبة بأسمائها دون إعادة الحساب في Angular.

### القبول

- كل API يحتفظ بصلاحيته المستقلة: `InventoryInsights.View` و`InventoryReconciliation.View`.
- لا توجد mutation؛ التصنيف والمجاميع والفروقات والترقيم تبقى خادمية.
- Angular ثنائي اللغة وRTL ويغطي التحميل والفراغ والخطأ والترقيم والمرشحات وحدود الإدخال.
- اختبارات الصلاحيات والعقود وبوابة القبول كاملة؛ MVC يبقى افتراضيًا.
