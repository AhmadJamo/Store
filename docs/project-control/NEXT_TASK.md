## `MOD-024G` — دفعات العملاء / Customer payments

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة المبيعات

اكتمل `MOD-024F`: جميع عمليات فواتير العملاء الحالية، بما فيها الترحيل والعكس، تعمل في Angular، وبقي MVC افتراضياً.

### الهدف

- نقل قائمة وتفاصيل وإنشاء دفعات العملاء وتوزيعها على الفواتير المرحلة المؤهلة.
- نقل الترحيل والعكس مع عرض التوزيعات والرصيد ودليل القيد المحاسبي.
- إبقاء أهلية العميل/العملة والأرصدة والتوزيع وفروق الصرف والترقيم والتزامن داخل الخادم.

### القبول

- كل عمليات Customer Payment الحالية ضمن النطاق تعمل وتُختبر في Angular عبر Application layer.
- لا يحسب Angular رصيدًا أو فرق صرف أو قيدًا موثوقًا، ولا تغيّر عملية التحصيل المخزون.
- كل mutation يحتفظ بصلاحيته وantiforgery وrowversion/idempotency حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
