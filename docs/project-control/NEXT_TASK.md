## UX-016 — قوالب القيود الدورية والتنفيذ المضبوط / Recurring Journal Templates and Controlled Runs

> الحالة: PROPOSED — AWAITING OWNER APPROVAL

اكتملت UX-015 بإقفال فترة مضبوط دون إنشاء قيود إقفال تلقائية. الخطوة التالية المقترحة تقلل العمل المتكرر في
الإيجارات والمصاريف الدورية مع إبقاء كل تشغيل مسودة قابلة للمراجعة؛ لذلك لا تبدأ دون موافقة مالك صريحة.

### النطاق المقترح

- قالب قيود متوازن باسم وتواريخ فعالية وتكرار وحسابات وأبعاد مسماة ضمن الشركة.
- توليد مسودة مستقلة بمعرف إعادة آمن؛ لا ترحيل تلقائي ولا تعديل لمسودة سابقة.
- صلاحيات مستقلة للعرض والإدارة والتشغيل، مع antiforgery وrowversion وسجل تدقيق.
- شاشة ثنائية اللغة تعرض موعد التشغيل التالي، آخر نتيجة، المسودة المنشأة ورابط مراجعتها.
- إعادة استخدام `ManualJournalService` وبوابة الترحيل الحالية؛ الفترات المالية تبقى السلطة النهائية عند الترحيل.

### خارج النطاق

- قيد إقفال الإيرادات/المصروفات، التوحيد، الموازنات، الاستحقاق الآلي أو جدولة خارجية بلا مراقبة.
- ترحيل المسودة تلقائيًا، تعديل قيد مرحّل أو تجاوز فترة مغلقة.

لا يبدأ التنفيذ قبل موافقة المالك على هذا النطاق وعلى سياسة التشغيل اليدوي مقابل الجدولة.
