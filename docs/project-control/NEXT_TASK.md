## `MOD-024E` — تسليمات المبيعات / Sales deliveries

### الهدف

- نقل قائمة وتفاصيل وإنشاء تسليمات المبيعات من حجوزات طلب البيع.
- نقل ترحيل وإلغاء المسودة مع عرض التتبع والحركة والكلفة والقيد الناتج.
- إبقاء أهلية الحجز والكميات والتتبع والتقييم والحركة الفعلية وCOGS والتزامن داخل الخادم.

### القبول

- كل عمليات Sales Deliveries الحالية تعمل وتُختبر في Angular عبر Application layer.
- المستودعات والمواقع تظهر بالأسماء، ولا يحسب Angular مخزونًا أو كلفة أو قيدًا موثوقًا.
- كل mutation يحتفظ بصلاحيته وantiforgery وrowversion/idempotency حيث ينطبق.
- Release وSecurityRegression وAngular tests/build والوصولية وexternal SCSS والميزانية تنجح.
- تحديث توثيق المرحلة وبقاء MVC افتراضياً حتى cutover مستقل.
