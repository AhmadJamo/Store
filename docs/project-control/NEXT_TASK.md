## `MOD-028C` — المسح التشغيلي للمخزون / Inventory Scanning

> الحالة: APPROVED — NEXT INCREMENT ضمن موجة الشاشات المتبقية

اكتمل `MOD-028B` لتحويلات المخزون وبقيت خمسة أسطح. شاشة المسح الحالية تجمع حل رموز المنتج والمستودع والموقع
ومستند الجرد مع ثلاث عمليات تشغيلية مستقلة الصلاحيات.

### الهدف

- نقل resolve/putaway/relocate/count إلى API داخلي صريح وواجهة Angular مهيأة للماسح ولوحة المفاتيح.
- الحفاظ على `InventoryScanResolver` وخدمات التسكين والنقل والجرد كجهات القرار الوحيدة.
- إظهار نتائج المسح بأسماء المنتج والمستودع والموقع مع إبقاء المعرفات داخلية.

### القبول

- القراءة تتطلب `InventoryScanning.View`، والتسكين والنقل والعدّ يحتفظ كل منها بصلاحيته الإضافية الحالية.
- كل mutation محمي بـantiforgery ولا يعيد تنفيذ قواعد المخزون داخل المتحكم أو Angular.
- Angular ثنائي اللغة وRTL، يدعم الإدخال السريع، الحالات الفارغة/الخاطئة، وحماية التكرار غير المقصود.
- اختبارات الصلاحيات والعمليات وبوابة القبول كاملة؛ MVC يبقى افتراضيًا.
