## `P2-CUS-040D / CUS-030` — إعدادات بيع ومحاسبة الزبون

> الحالة: PROPOSED — AWAITING EXPLICIT APPROVAL
> (مقترحة وتنتظر الموافقة الصريحة)

> الاعتماد السابق: اكتمل `CUS-020` في 2026-10-18 بجهات اتصال وعناوين متعددة مع عزل وتزامن وافتراضيات مضبوطة.

### الهدف

تحديد وإضافة إعدادات البيع والمحاسبة التي تخص الزبون: شروط الدفع، العملة، قائمة السعر، مندوب/فريق البيع،
الوضع الضريبي ونمط حساب الذمم، دون إنشاء محرك تسعير أو ذمم موازٍ.

### بوابات القرار قبل الكود

- حسم حساب ذمم مستقل لكل زبون أو حساب رقابة مشترك مع دفتر فرعي.
- إعادة استخدام التسعير والضرائب القائمة والتنسيق مع `SAL-020` (مرحلة التسعير والضريبة).
- تحديد الحقول التي يجوز أن تتغير واللقطات التي يجب تثبيتها في المستندات المستقبلية.
- عدم تعديل المبيعات التاريخية أو اعتبار البيع القديم طلب بيع احترافيًا.

### خارج النطاق

- الائتمان والموافقات والتحصيل والتقادم.
- عروض الأسعار وطلبات البيع والتسليم وفواتير الذمم.
- `BusinessPartner` (شريك أعمال موحد).

لا يبدأ التنفيذ قبل موافقة المستخدم الصريحة على هذه المرحلة وقراراتها المحاسبية.
