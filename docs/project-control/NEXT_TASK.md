## UX-014 — قائمة التدفقات النقدية وجاهزية الإغلاق / Cash Flow and Period-Close Readiness

> الحالة: PROPOSED — AWAITING OWNER APPROVAL

بعد اكتمال القوائم الأساسية وأعمار الذمم، ما زال المحاسب يفتقد قائمة تدفقات نقدية قابلة للتتبع ولوحة توضح
عوامل منع إغلاق الفترة قبل تنفيذ أي إغلاق فعلي.

### النطاق المقترح

- قائمة تدفقات نقدية خادمية بطريقة غير مباشرة من القيود المرحّلة، مصنفة تشغيلية واستثمارية وتمويلية.
- إعداد واضح وآمن لتصنيف حسابات النقد والحركات غير النقدية دون تغيير القيود.
- لوحة جاهزية فترة تعرض القيود غير المتوازنة أو المسودات اليدوية والفروقات في الذمم والمخزون والفترات المفتوحة.
- روابط دليل إلى القيود والتقارير والمستندات المسببة، مع حفظ فلاتر آمنة فقط.
- واجهة ثنائية اللغة ومتجاوبة، قراءة فقط، مع اختبارات بيانات ذهبية وRTL/LTR.

### خارج النطاق

- تنفيذ إغلاق أو إعادة فتح الفترة، قيود إقفال آلية، التوحيد متعدد الشركات، الموازنات أو التنبؤ النقدي.
- تعديل مستندات تشغيلية أو إعادة تقييم العملات أو إنشاء دفعات.

لا يبدأ التنفيذ قبل موافقة المالك على هذا النطاق.
