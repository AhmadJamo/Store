> التاريخ: 2026-10-15
>
> النطاق: قاعدة `MiniStoreDb` المحلية المصنفة `Demo` (تجريبية)

## أهداف الاستعادة المعتمدة لبيئة Demo

- `RPO` (أقصى فقد بيانات مقبول): 24 ساعة عند اعتماد تشغيل نسخة يومية.
- `RTO` (أقصى زمن استعادة مقبول): 4 ساعات.
- المالك الحالي: مالك المشروع والجهاز المحلي.
- هذه القيم لا تعتمد تلقائيًا للإنتاج؛ يجب أن يقرها مالك العمل والاستضافة قبل إطلاق الإنتاج.

## النسخة والحماية

| البند | الدليل |
|---|---|
| المصدر | `MiniStoreDb` على SQL Server Developer 16.0 المحلي |
| نوع النسخة | `COPY_ONLY` (نسخة مستقلة لا تغيّر سلسلة النسخ) |
| التشفير | `AES_256` بواسطة شهادة SQL Server |
| السلامة | `CHECKSUM` مفعّل و`RESTORE VERIFYONLY` ناجح |
| الحجم المنطقي | 42,024,960 بايت |
| الحجم المضغوط | 1,926,768 بايت |
| ملف النسخة | `C:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\Backup\MiniStoreDb_Demo_20261015_195552.bak` |
| شهادة الاستعادة | `MiniStoreDemoBackupCertificate.cer` في مجلد النسخ نفسه |
| المفتاح الخاص | `MiniStoreDemoBackupCertificate.pvk` مشفّر في مجلد النسخ نفسه |
| أسرار الحماية | خارج المستودع في `User Secrets` تحت المعرّف `MiniStore-Backup-Drill` |

لا يحتوي المستودع أو هذا الدليل كلمة مرور الشهادة أو المفتاح الرئيسي.

## تجربة الاستعادة

1. استعيدت النسخة باسم `MiniStoreDb_RestoreDrill_20261015_195552` مع ملفات بيانات وسجل منفصلة.
2. ضُبطت القاعدة المستعادة `READ_ONLY` (للقراءة فقط) لمنع أي تعديل عرضي.
3. نجح `DBCC CHECKDB` (فحص سلامة قاعدة البيانات) بلا أخطاء.
4. قورنت القاعدة المستعادة بالأصل:
   - 147 جدولًا؛ صفر اختلاف في أعداد السجلات.
   - 21 فحص أعمال؛ صفر اختلاف.
   - الشركات والمستخدمون متطابقون.
   - كميات وقيم `ProductStocks` (مخزون المنتجات) متطابقة.
   - أرصدة `InventoryBalances` (أرصدة المخزون) والمتاح المحجوز متطابقة.
   - حركات المخزون وقيمها متطابقة.
   - أعداد ومجاميع مدين/دائن للقيود متطابقة ومتوازنة في الأصل والاستعادة.
   - أوامر الشراء والاستلامات وفواتير ودفعات الموردين متطابقة.
   - `Outbox` (صندوق رسائل التكامل) ومحاولاته متطابقة.
5. كان تنفيذ النسخ والاستعادة الفعلي بالثواني، أي أقل بكثير من هدف الأربع ساعات.
6. بعد نجاح الدليل، تحقق النظام من نمط الاسم ثم حذف قاعدة `RestoreDrill` المعزولة فقط. بقيت القاعدة الأصلية
   والنسخة المشفرة ومواد استعادة الشهادة دون تغيير.

## القيود المتبقية

- ملف النسخة موجود على الجهاز والقرص نفسيهما؛ هذا يثبت قابلية الاستعادة لكنه لا يحمي من فقد الجهاز أو القرص.
- لا توجد بعد وجهة `off-host` (خارج الجهاز) أو جدول تلقائي أو تنبيه فشل أو سياسة احتفاظ منفذة.
- لا توجد بيئة إنتاج مثبتة. قبل الإنتاج يجب نسخ ملف النسخة والشهادة والمفتاح الخاص المشفّر إلى وجهة منفصلة
  بصلاحيات محدودة، واختبار الاستعادة على خادم آخر.
- المفتاح الرئيسي والشهادة أصول تشغيلية؛ لا تحذف من SQL Server أو مجلد النسخ قبل إثبات نسخة خارجية قابلة
  للاسترجاع.
