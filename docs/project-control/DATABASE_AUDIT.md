# تدقيق قاعدة البيانات / Database Audit

## الوضع المثبت

- `SQL Server` (خادم قاعدة بيانات) عبر `EF Core 10.0.12` (إطار الوصول للبيانات).
- خط أساس `P0-DB-003` من 112 ترحيلًا، ثم ترحيلا AuditEvents والاحتفاظ وترحيلات CUS-010/020/030A/030B وSAL-020B وSAL-030/040/050/060/070؛ مصدر الكود وDemo عند 124 ولقطة النموذج مطابقة.
- كل نوع تشغيلي مصنف مركزيًا كملكية شركة أو كنوع غير تشغيلي.
- فهارس فريدة خاصة بالشركة وعلاقات مركبة `(Id, TenantId)` تمنع الربط العابر للشركات.
- `RowVersion` (نسخة الصف) مستخدمة في الأرصدة والمستندات والإعدادات عالية المخاطر.
- اختبار تكامل قاعدة البيانات نجح في 2026-10-15.

## قواعد إلزامية لاحقة

لا حذف ترحيلات، ولا تعديل ترحيل مطبق، ولا ترحيل هدّام تلقائي. كل تغيير يتبع:
Expand → Backfill → Verify → Switch → Contract (توسعة ثم تعبئة ثم تحقق ثم تحويل ثم إزالة مؤجلة).
