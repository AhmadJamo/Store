# سياق سريع للمشروع / Project Context

`MiniStore` نظام `ERP SaaS` (تخطيط موارد المؤسسات كخدمة) متعدد الشركات على `.NET 10`, `ASP.NET Core MVC`,
`EF Core 10` و`SQL Server` (خادم قاعدة بيانات). المعمارية تطبيق موحد مقسم بأربع طبقات:
Web → Application → Domain، وتنفذ Infrastructure عقود التخزين والتكامل.

الوحدات التشغيلية: الكتالوج، الموردون، المشتريات الحديثة، المستودعات والمخزون والتتبع، النقل، البيع الفوري
وPOS (نقطة البيع)، المحاسبة الأساسية، الإعدادات، الهوية والصلاحيات، التسجيل والخطط والاشتراكات.

ملف الزبون الاحترافي وقوائم أسعار المبيعات وعروض الأسعار وطلبات البيع وحجزها منفذة؛ التسليمات والذمم ما تزال مخططة. `Sale` الحالي بيع فوري ولا يعاد تفسيره كطلب
أو فاتورة ذمم. `Purchase` القديم تاريخي، والمدخل الجديد هو Purchase Request (طلب شراء). المخزون والمحاسبة
لهما سلطات مستقلة، وكل بيانات الأعمال مقيدة بالشركة.

آخر تحقق: بناء Release (نسخة الإصدار) بلا تحذيرات أو أخطاء، و862 فحص انحدار ناجح، و122 ترحيلًا في المصدر بلا تغيير نموذج معلق في 2026-10-20. قاعدة Demo مطابقة عند 122، واختبار SQL الشامل نجح بما فيه الحجز الجزئي والتحرير وإعادة التخصيص والتنافس على آخر وحدة. النسخ والاستعادة مثبتان محليًا فقط؛ الإنتاج غير مثبت بسبب غياب نسخة خارج الجهاز وCI/CD (البناء والنشر الآلي) والتحميل والمراقبة.
