# Permission Code Export

This folder is a standalone copy of the permission-related code from MiniStore, preserving the original project structure.

Included areas:

- Permission and role-permission domain entities.
- Permission definitions, application contract, and the discount-override permission use case.
- Entity Framework context, mappings, migrations, and seeders.
- Permission authorization attribute, policy provider, requirement, and handler.
- Dependency-registration and startup code in `MiniStore.Web/Program.cs`.
- Controllers protected by permissions, role and user management, and the related Razor views.

The source project was not changed.
